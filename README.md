# 🌱 Thaali Zero
### Cook what will be eaten.

**Thaali Zero** is an AI-powered food waste reduction and redistribution ecosystem designed for college canteens, hostels and mess kitchens.

## 🚨 Problem Statement
Large amounts of food are wasted in canteens and mess kitchens due to inaccurate demand prediction and inefficient surplus food management.

## 💡 Our Solution
Thaali Zero helps kitchens predict meal demand, identify surplus food and coordinate food redistribution to reduce food waste.

## ✨ Key Features
- 📊 Meal demand forecasting
- 🤖 Automated surplus detection
- 🍱 Leftover food management
- ❤️ Food donation coordination
- 🗺️ Route planning
- 📈 Food waste and impact dashboard
- 🌐 Multilingual interface

## 🛠️ Technologies Used
- HTML
- CSS
- JavaScript
- Node.js
- Database integration
